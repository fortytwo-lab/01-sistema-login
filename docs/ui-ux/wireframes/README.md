# 🖱️ Protótipos

Esta pasta registra os protótipos utilizados para representar
a navegação e a interação entre as telas da aplicação.

## Fluxo inicial

### Login válido

Tela de Login → Validação → Tela de Seleção

### Login inválido

Tela de Login → Mensagem de erro → Tela de Login

### Agenda de Contatos

Tela de Seleção → Agenda de Contatos

### Projeto Livre

Tela de Seleção → Projeto Livre

### Voltar

Tela de Seleção → Tela de Login

> Os protótipos representam o comportamento planejado para a aplicação
> e poderão ser refinados durante o desenvolvimento.
