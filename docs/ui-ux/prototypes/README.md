# 🖱️ Protótipos

Esta pasta registra os protótipos de navegação e interação desenvolvidos
durante o planejamento da interface.

## Fluxo inicial

Tela de Login → Tela de Seleção

### Login válido

Tela de Login → Validação → Tela de Seleção

### Login inválido

Tela de Login → Mensagem de erro → Tela de Login

### Retorno

Tela de Seleção → Voltar → Tela de Login

> Os protótipos representam o planejamento da aplicação e poderão sofrer
> alterações durante o desenvolvimento.
