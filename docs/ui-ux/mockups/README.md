# 🖼️ Mockups

Esta pasta contém os mockups desenvolvidos para representar visualmente
como as interfaces poderão ser apresentadas ao usuário.

Os mockups acrescentam elementos como:

- cores;
- tipografia;
- ícones;
- imagens;
- identidade visual;
- organização visual dos componentes.

## Mockups atuais

- `tela-login-v1.png`
- `tela-selecao-v1.png`

Os mockups servem como referência para o desenvolvimento das interfaces
em Java Swing.

> O mockup representa uma proposta visual e poderá sofrer alterações
> durante a implementação.
