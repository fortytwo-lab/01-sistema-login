# 📚 Documentação

Esta pasta reúne a documentação produzida pela equipe durante o planejamento,
desenvolvimento e apresentação do projeto.

## Estrutura

- `uml/` — diagramas UML.
- `ui-ux/` — planejamento e design das interfaces.
  - `wireframes/`
  - `mockups/`
  - `prototypes/`
- `diagrams/` — fluxogramas e outros diagramas do projeto.
- `presentations/` — apresentações utilizadas nas avaliações e demonstrações.
