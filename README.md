# 🔐 Sistema de Login

Sistema de autenticação desenvolvido pela **FortyTwo Lab** como parte do
Projeto Final da disciplina de Programação Orientada a Objetos.

O projeto será desenvolvido em **Java**, utilizando **Swing** para construção
da interface gráfica.

---

## 🎯 Objetivo

Desenvolver um sistema simples de autenticação que permita validar as
credenciais do usuário e, após o login, direcioná-lo para uma tela de seleção
dos demais módulos desenvolvidos pela FortyTwo Lab.

---

## ⚙️ Funcionamento

O fluxo inicial da aplicação será:

Tela de Login → Validação → Tela de Seleção

Na versão inicial, serão utilizadas as seguintes credenciais:

- **Usuário:** `root`
- **Senha:** `toor`

Caso as credenciais estejam corretas, a aplicação abrirá a **Tela de Seleção**.

A Tela de Seleção disponibilizará acesso aos seguintes módulos:

- 📒 Agenda de Contatos
- 🚀 Projeto Livre
- ↩️ Voltar para a Tela de Login

Os módulos Agenda de Contatos e Projeto Livre serão integrados posteriormente.
