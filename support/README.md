# 🧰 Materiais de Apoio

Esta pasta reúne materiais externos e auxiliares utilizados como apoio
durante o desenvolvimento do projeto.

## Estrutura

- `documents/` — documentos, apostilas, manuais e artigos.
- `videos/` — referências para vídeos e videoaulas.
- `tutorials/` — tutoriais e guias utilizados pela equipe.
- `references/` — links, documentações oficiais e referências técnicas.
